# Gemini Live  Dub

یک افزونه‌ی Chrome/Chromium برای دوبله‌ی زنده‌ی گفتار فارسی و انگلیسی روی صفحه‌ی  با استفاده از Gemini، OpenAI یا هر سرویس سازگار با OpenAI.

## معرفی کوتاه

این پروژه یک افزونه‌ی  است که:

- صدای صفحه‌ی فعال را ضبط می‌کند
- گفتار را تشخیص می‌دهد و ترجمه می‌کند
- ترجمه را به زبان مقصد تبدیل به گفتار می‌کند
- در صورت نیاز، زیرنویس فارسی/انگلیسی روی صفحه نمایش می‌دهد


هدف اصلی پروژه، افزودن قابلیت دوبله‌ی هم‌زمان و زنده برای جلسات  است.

---

## ویژگی‌ها

- ترجمه و دوبله‌ی دوطرفه بین فارسی و انگلیسی
- تشخیص خودکار گفتار با Gemini STT
- ترجمه‌ی متنی به زبان مقصد
- تولید گفتار با Gemini TTS
- پخش دوبله روی همان تب باز
- حذف یا کم‌کردن صدای اصلی با تنظیم میزان صدا
- نمایش زیرنویس‌های  و/یا متن اصلی


---

## سرویس‌دهنده‌ها (Providers)

از پاپ‌آپ یکی را انتخاب کنید:

| Provider | نوع | نکته |
|---|---|---|
| Gemini Live | استریم صدا→صدا | مثل قبل |
| OpenAI Realtime Translate | استریم صدا→صدا (`gpt-realtime-translate`) | خروجی فقط ۱۳ زبان (en, es, pt, fr, de, it, ru, zh, ja, ko, hi, id, vi) — **فارسی خروجی ندارد**. این فهرست از یک منبع غیررسمی است. |
| پایپ‌لاین STT → LLM → TTS | VAD → `/audio/transcriptions` → `/chat/completions` → `/audio/speech` | با OpenAI، Groq، سرور محلی و هر API سازگار کار می‌کند؛ تأخیر ≈ یک جمله. |

- اگر OpenAI Realtime انتخاب شده باشد و زبان مقصد در فهرست بالا نباشد (مثلاً شنیدن صدای طرف مقابل به فارسی)، همان مسیر به‌صورت خودکار با پایپ‌لاین انجام می‌شود؛ بنابراین گفتار شما → انگلیسی با Realtime و صدای او → فارسی با پایپ‌لاین.
- برای سرور سازگار غیر OpenAI، Base URL را عوض کنید؛ مرورگر هنگام «شروع» اجازه‌ی دسترسی به آن دامنه را می‌پرسد. مدل TTS را خالی بگذارید تا فقط زیرنویس داشته باشید.
- OpenAI Realtime نیاز به هدر `Authorization` دارد که WebSocket مرورگر نمی‌تواند بفرستد؛ افزونه در زمان اجرا با یک قانون `declarativeNetRequest` (فقط برای درخواست‌های خود افزونه) آن را اضافه و هنگام توقف حذف می‌کند.
- ساختار کد: `providers.js` (همه‌ی adapterها)، `background.js` (مسیر میکروفون)، `offscreen.js` (مسیر صدای تب).
