# Gemini Live  Dub

یک افزونه‌ی Chrome/Chromium برای دوبله‌ی زنده‌ی ترجمهگفتار روی صفحه‌ی با استفاده از Gemini API.

## معرفی کوتاه

این پروژه یک افزونه‌ی  است که:

- صدای صفحه‌ی فعال را ضبط می‌کند
- گفتار را تشخیص می‌دهد و ترجمه می‌کند
- ترجمه را به زبان مقصد تبدیل به گفتار می‌کند
- در صورت نیاز، زیرنویس فارسی/انگلیسی روی صفحه نمایش می‌دهد

هدف اصلی پروژه، افزودن قابلیت دوبله‌ی هم‌زمان و زنده برای جلسات Live Google AI Studio است.

---

## ویژگی‌ها

- تشخیص خودکار گفتار با Gemini STT
- ترجمه‌ی متنی به زبان دلخواه
- تولید گفتار با Gemini TTS
- پخش دوبله روی همان تب باز
- حذف یا کم‌کردن صدای اصلی با تنظیم میزان صدا
- نمایش زیرنویس‌های  و/یا متن اصلی
