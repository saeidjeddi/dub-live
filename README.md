# Gemini Live  Dub

یک افزونه‌ی Chrome/Chromium برای دوبله‌ی زنده‌ی گفتار فارسی و انگلیسی روی صفحه‌ی  با استفاده از Gemini API.

## معرفی کوتاه

این پروژه یک افزونه‌ی  است که:

- صدای صفحه‌ی فعال را ضبط می‌کند
- گفتار را تشخیص می‌دهد و ترجمه می‌کند
- ترجمه را به زبان مقصد تبدیل به گفتار می‌کند
- در صورت نیاز، زیرنویس فارسی/انگلیسی روی صفحه نمایش می‌دهد


هدف اصلی پروژه، افزودن قابلیت دوبله‌ی هم‌زمان و زنده برای جلسات  است.

---

## ویژگی‌ها

- ترجمه و دوبله‌ی دوطرفه بین فارسی و انگلیسی
- تشخیص خودکار گفتار با Gemini STT
- ترجمه‌ی متنی به زبان مقصد
- تولید گفتار با Gemini TTS
- پخش دوبله روی همان تب باز
- حذف یا کم‌کردن صدای اصلی با تنظیم میزان صدا
- نمایش زیرنویس‌های  و/یا متن اصلی
- رابط پاپ‌آپ دوزبانه (فارسی/انگلیسی): از منوی زیر هدر انتخاب می‌شود؛ پیش‌فرض فارسی است.
- ترجمه متن‌های صفحه: با روشن کردن «ترجمه متن‌های صفحه به زبان شما» متن‌های قابل‌مشاهده‌ی تب فعال (و متن‌های جدید/اسکرول‌شده) ترجمه می‌شوند و با خاموش کردن، متن اصلی برمی‌گردد. متن صفحه با API Key شما به Gemini ارسال می‌شود.
